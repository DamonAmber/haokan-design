# 本地预览规范（AI 必须遵循）

本项目的**所有本地预览统一在 `http://localhost:4173/` 查看**。用户默认会在这个地址看效果，不要换别的端口或让用户去双击某个 HTML 文件。

## 怎么起预览

预览服务就是设计资产库画廊：

```bash
npm run gallery
```

启动后访问 `http://localhost:4173/`。画廊里能浏览所有资产、打开详情页看：

- **规范**：设计语言（色板 / 字阶 / 间距 / 动效）。
- **样张**：用这套资产 token 生成的中立示例页（`/packs/<name>/demo.html`）——最直观地展示"用了这套设计资产会生成什么"。
- **微调**：改 token 或分层混合，实时看样张，存为新资产。

## 端口约定（重要）

- `src/gallery/server.js` 默认监听 `4173`；**若 4173 被占用会自动顺延到 4174、4175…**。这会让预览不再在约定地址，违背本规范。
- 因此启动前若 4173 被占用，**先释放它**（结束占用进程或关掉旧的画廊/`vite preview`），确保画廊真正跑在 `4173`。
- 需要指定端口时用 `PORT=4173 npm run gallery`。
- 桌面 App（`npm run app`）内嵌同一画廊服务，预览能力一致。

## 给 AI 的操作要求

- 验证样张 / 编辑器 / 对比等前端改动时，一律通过 `http://localhost:4173/` 检查，不要临时改用其它端口或路径。
- 若发现服务落在 4174+，说明 4173 被占用——先清理再重启，别将就。
- 单个资产的静态预览页仍在 `output/<name>/preview.html`，但**对用户展示效果时优先走 `http://localhost:4173/`**。
